## Business-rule provenance

The JP7 business rules in this release were ported from
**[Team-Haruki/sekai-deck-recommend-cpp](https://github.com/Team-Haruki/sekai-deck-recommend-cpp)**
at commit [`496caed78a07ffe1f2d1f1553047dbf6b2ed0314`](https://github.com/Team-Haruki/sekai-deck-recommend-cpp/commit/496caed78a07ffe1f2d1f1553047dbf6b2ed0314).
This includes multi-unit area-item effects, MySEKAI gates, finale identification,
and World Link limits and bonuses. The business rules are implemented in the
Rust engine's own data model and exact-search routines.

Master-table shuffle overrides and browser integration cases also draw on
[Moesekai's public patch series](https://github.com/StarMoe-org/Moesekai/tree/d0e7cd4cd5cdea25756945806f001dfdfdb3111e/web/vendor/allium-deck-wasm/patches).
See the [source map](https://github.com/empty-sekai/allium-deck/blob/v0.1.0/docs/game-rule-sources.md)
for file-level references, upstream attribution, and deliberate differences.

## Compatibility

This release includes the public API changes since 0.0.15. Search outcomes carry
an explicit completion status; a timed-out result does not establish complete
Top-K. Typed integrations must update their data structures, and browser
consumers must preserve the returned completion status.

The default fixed-card and fixed-character contract remains ordered slots.
Explicit finale membership constraints let consumers require participation
without making the first fixed card the leader.
